# 🧩 拼豆图纸制作器（Perler Bead Pattern Maker）

一个**纯前端、单文件（index.html）**的拼豆图纸制作工具：上传图片自动转成带色号的拼豆图纸，也可以抠图、导入已有图纸、从零绘制，或以图片为底板用透明网格“描图+智能推荐选色”。所有数据只保存在本机浏览器，无需服务器，支持手机（iOS/Android）与深色模式。

> 把 `index.html` 用浏览器打开即可使用，也可直接部署为静态网页。
> 若要部署到网络服务器，将 `index.html` 与 `README.md` 一起上传即可。

## ✨ 功能一览

### 1. 色板（拼豆色号）
- **221 色 / 291 色 = MARD 官方色号**（数据来源 pixel-beads.com 的「MARD 拼豆色号大全」）：标准 221 色为 A–H、M 系列，扩展 70 色为 P/Q/R/T/Y/ZG，色号形如 `A1`、`B12`、`ZG8`，每色带 HEX。
- 另提供 **36 / 57 / 96 / 298 色** 近似色板（算法生成，中文近似名）。
- 更换色板时，图纸上已使用的颜色会自动按“最接近”原则映射到新色板。

### 2. 网格
- 宽、高均可独立设置为 **5 × 5 ～ 128 × 128**。
- 编辑器内可继续调整尺寸（⋯ 菜单 → 调整网格尺寸）。
- 底图/生成流程支持“保持原图比例自动适配”或手动指定宽高。

### 3. 制作方式（首页五张卡片）
| 卡片 | 说明 |
|---|---|
| 🖼️ 上传图片 → 自动生成 | 上传图片 → 网站自动把每个格子颜色近似成所选色板最接近的拼豆色号，并**逐格标注色号**；可选手动/自动尺寸与颜色抖动（Floyd–Steinberg） |
| ✂️ 抠图后再生成 | 上传后**自动去背景**，也可魔棒 / 全局删相似色 / 橡皮 / 恢复笔手动精修；完成后**直接进入拼豆参数设置**，透明处自动留空再生成 |
| 📂 导入已有图纸修改 | 打开本地草稿，或导入 图片 / 文本色号 / `.pindou` 工程文件继续修改 |
| 📄 空白图纸自绘 | 选择 5×5 ~ 128×128 网格从零绘制 |
| 🖍️ 底图描图 | 图片为底板 + 上层透明网格纸；打开全部色板选色后点格子染色，或用「✨ 智能推荐」点格子自动推荐最接近色号 |

### 4. 编辑器 / 绘制工具
- **画笔 / 橡皮 / 取色 / 填充 / 抓手**，拖拽连续涂色，右键擦除，全部操作可**撤销/重做**。
- 画布支持 **滚轮 / 双指缩放**，以及 **✋ 抓手工具 / 按住空格拖动 / 双指拖动 / 鼠标中键拖动** 平移（绘制与抠图界面均支持）；实时显示鼠标所在格子坐标与颜色。
- 网格线、格内色号显示可开关；放大后自动显示格内色号。
- 图板为透明网格：已涂的格子上色，空白格透出底图（描图模式）或纸张底色。

### 5. 保存与导出
- **💾 保存草稿**：存入浏览器本地草稿箱（localStorage），首页/草稿箱随时打开继续修改；未保存的工作还会**自动暂存**，下次打开可一键恢复。
- **⬇ 导出**：
  - **PNG 图纸**：顶部信息栏（图纸名 / 尺寸 / 色板 / **总豆数** / 颜色数）+ 每格色号 + 色号图例（名称/色值/用量）+ 底部“总计需豆子”，可调每格像素、是否含底图（空白格：白色 / 按底图近似 / 透出底图原样）；
  - **文本色号表**：每行一行图纸（0=空白，1~N=色号），附色号对照表；
  - **工程文件 `.pindou`**：完整保留底图与网格，可再次导入编辑。

### 6. 兼容与体验
- **所有提示/确认/输入均为模态框**，不使用 `alert/confirm/prompt`，兼容 iOS 弹窗限制。
- 移动端适配：大按钮、底部工具栏、双指缩放、`viewport-fit=cover` 安全区、触控绘制。
- **深色模式**：右上角 🌙/☀️ 一键切换并记忆，跟随系统默认。

## 🚀 使用方法

1. 用浏览器（推荐最新版 Chrome / Edge / Safari / 微信内置浏览器）打开 `index.html`。
2. 首页选择制作方式，例如「上传图片 → 自动生成」：
   - 上传图片 → 选色板（221 色 / 291 色 / 298 色…）→ 设置网格 → 看实时预览 → 点“生成图纸”。
3. 在编辑器里修改颜色（🎨 全部色号 / 💉 取色 / ✨ 智能推荐…）。
4. 点 💾 保存草稿，或 ⬇ 导出 PNG / 文本 / 工程文件。
5. 纸铺拼豆时照着 PNG 里的格号放对应色号即可。

> 手机上：点击上传按钮时通常会出现“拍照/从相册选择”选项（取决于浏览器）。

## 🧠 技术说明

- **色板生成**：`buildPalette(N)` 先建立灰阶，再用黄金角采样 HSV 生成 `N - 灰阶数` 个彩色样本，最后按色相族排序并编号；同色号自动微扰避免完全重复。色号顺序稳定可复现。
- **MARD 色板**：221 / 291 色使用 MARD 官方色号与 HEX（数据内置于页面，来自 pixel-beads.com 2026 修订版，为屏幕近似值；ZG 为光变系列，取 UV 显色端）。
- **颜色匹配**：sRGB → Lab（CIE 76）最近邻匹配，比普通 RGB 距离更符合人眼。
- **抖动**：网格级别的 Floyd–Steinberg 误差扩散，让渐变更平滑（可选）。
- **底图取样**：读取底图在对应格子上方的平均颜色（含透明处理），用于「智能推荐」与“空白按底图近似”导出。
- **抠图**：全本地像素级编辑，含**自动去背景**（取四边背景色 + 连通域泛洪删除）、魔棒 / 全局相似色 / 橡皮 / 恢复笔，透明信息保留到 PNG。
- **草稿/自动保存**：`localStorage`（`pd.drafts.v1`、`pd.autosave.v1`、`pd.prefs`），请勿在隐私/无痕模式长期依赖。
- **无任何网络请求**：图片不上传，隐私安全。

## ⚠️ 已知限制

- 图纸/草稿保存在当前浏览器本地：清缓存、换设备或换浏览器会丢失（可先用“导出 → 工程文件”备份）。
- 草稿含底图时体积较大，本地存储约 5 MB，空间不足时请删除旧草稿。
- 超大图会被自动缩小到约 1024 px 参与处理；如需细节建议原图清晰并选 128×128 网格。
- MARD 色号为官方色号，但 HEX 为屏幕近似值，实色受批次/光线影响；ZG（光变）系列未感光时为透明白、感光后显色。铺豆前建议先用手头色卡核对（导出图例含 HEX）。
